# Repository Notes

- This is a notebook-oriented Python workspace; the project notebooks are `tensorflow_test.ipynb` and `Untitled.ipynb`.
- Install the declared notebook and data-science dependencies with `venv/bin/python -m pip install -r requirements.txt`.
- The local `venv` was created with Python 3.11; use `venv/bin/python` for scripts and `venv/bin/jupyter lab` to open the notebooks.
- Run the included smoke script with `venv/bin/python hello.py`.
